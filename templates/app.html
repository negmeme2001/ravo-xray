Reading the x-ray

Under every answer is a strip of film. Its length is the whole turn; each band is one step, sized by the time it took.

  • Thinking and writing: the language model deciding what to look up, then writing the answer.
  • Understanding the question: turning it into an embedding. A cache hit makes this band almost vanish.
  • Searching: finding the closest products or document passages in Postgres.
  • Amber marks the step that cost the most.

Ask the same question twice and watch the second band shrink.

Where a 3-second answer spends its time

I rebuilt the search path locally to profile it before changing anything. The database was never the problem: the expensive step in retrieval is the call that turns a question into an embedding.

Every change to search gets a score

A fixed set of shopper questions, each with a known right answer, run against every version of the search. This is what lets a team say "search got better" with a number instead of a feeling.

    How this plugs into Ravo

    • The cache

      One Redis lookup before the embedding call. Ravo already runs Redis, so a repeated question skips about half a second.

    • The x-ray

      Timing around the embedding call, the search and each language-model call, written into the logging Ravo already has. The 3 seconds becomes a breakdown anyone can read.

    • The scoreboard

      A labelled question set per store, run on every release. Search quality can be checked before it reaches a kiosk.

    What comes next

    1. Keyword and meaning together. Hybrid search in the same Postgres, so exact brand and product names stop slipping. Measured by the brand questions above.
    2. No more five copies of one product. Collapse near-duplicates so the top results show real choices. Measured by result variety.
    3. Understanding "not" and "without". Rewrite negated questions before searching. Measured by the negation questions above.
    4. The same assistant, spoken. Voice with streaming speech recognition, so the kiosk hears the shopper while they are still talking.
